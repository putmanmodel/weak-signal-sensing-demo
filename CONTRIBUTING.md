# Contributing

Thanks for your interest in this project.

This repository is a **simulation-oriented proof-of-behavior demo** for a layered weak-signal sensing architecture. Contributions are welcome, but they should strengthen the clarity, rigor, or usefulness of the demo rather than expanding it into an operational system.

## Good contributions

Examples of helpful contributions include:

- clearer scenario design
- better visualization of state transitions
- improved documentation
- reproducibility improvements
- cleaner baseline comparisons
- additional synthetic scenarios that stay within scope
- small bug fixes or code cleanup

## Out of scope

This repository is **not** intended for:

- interception logic
- engagement logic
- weapons integration
- operational targeting
- real-world deployment claims
- unsupported performance claims

## Before making major changes

If you want to propose a significant change, please open an issue first and explain:

- what you want to change
- why it improves the demo
- how it fits the project scope

## General expectations

Please keep contributions:

- simulation-oriented
- technically clear
- well-scoped
- easy to inspect
- consistent with the paper-backed architecture in this repo
